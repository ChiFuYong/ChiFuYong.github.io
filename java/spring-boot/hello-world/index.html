    SpringBoot 入门案例

    chify2019-12-152022-04-29

    SpringBoot 优势

      SpringBoot是 Spring 家族下的一个新框架，其秉承了约定大于配置的理念，避免了以往开发 Spring 应用中的各种复杂 xml 配置，其优势如下：

    • 简化了 Spring 应用的搭建和开发，提高了生产力，缩短了开发时间。
    • 嵌入式的 Tomcat、Jetty，不再需要使用 war 的方式去部署。
    • 使用约定好的 starter 来配置 pom.xml 文件，使 Maven 配置起来更加简单。
    • SpringBoot 会自动管理各个所需开源框架 jar 包的版本，不需要自己去调整配置。
    • 整合了大量流行的开源框架，方便使用，也为 SpringCloud 奠定了基础。

      这还只是用到了 SpringMVC 这一个 MVC 框架，假如用到了 MyBatis 或者其他框架技术，又会多出许多纷繁复杂的配置文件，配置这些将是一件非常麻烦的事情，为了解决这些各种复杂配置问题 Spring 家族就推出了 SpringBoot 技术。

      总而言之，SpringBoot 的关键点就是约定大于配置，配置、开发、部署都比以往更简单了，可以快速地开发出一个基于 Spring 的 Web 应用。

      注意：SpringBoot 不是对 Spring 的增强，而是让我们能够进行快速的 Spring 应用开发。

    学习 SpringBoot 前需要掌握的知识点

    1. 熟悉 Java 语言及 JavaEE 开发
    2. 熟悉 Spring 知识点
    3. 熟悉 SpringMVC 知识点
    4. 熟悉 Maven 构建工具

      在开始学习 SpringBoot 之前，这四个知识点是必须要先掌握的，秉承着饭要一口一口吃的理念，假如还没有掌握上面的知识点，就需要先从上面的知识点开始学起，要不然接下去的内容没有这些基础，想要学好是不太可能的！

      其实话说到这里，不得不提一下个人见解，学习这些应用层的框架技术和工具并不算是特别难的事情，对于初学者到网上找相关的学习视频来学习，结合书本，多动手实践和总结很快也就能够掌握。真正难的是：数据结构与算法、计算机组成原理、操作系统、计算机网络、编译原理、汇编语言，这些才是 IT 人的内功，把这些计算机基础知识融汇贯通才能算是真正的了解了计算机，在我眼里这也是真正衡量一个人有没有计算机素养的标准，当然任重道远，自己离这个标准还很远，不过人生很长，相信我总会达到这一境界的，而且就在不久后。
