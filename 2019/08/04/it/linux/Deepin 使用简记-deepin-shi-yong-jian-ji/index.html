Deepin 使用简记

chify2019-08-042022-04-28

一、系统预装、应用商店软件

  以下软件软件都可以在应用商城中下载安装，简单快捷，省的折腾：

  • Chrome
  • FireFox
  • 网易云
  • WPS
  • 微信（wine）
  • TIM（wine）
  • 雷鸟邮件
  • 百度云（Linux版）
  • gedit 文本编辑器
  • Notepadqq
  • electerm ssh、sftp工具
  • Xmind ZEN 思维导图
  • KolourPaint 画图
  • MyPaint 作图软件
  • Gvim

二、常用软件、开发工具安装

  • JDK、Eclipse
    　JDK、Eclipse 安装与配置 点击这里

  • eletron-ssr
    一直喜欢用这款软件，使用方便简单，搭完梯子才好同步 Chrome 书签。。。
    GitHub下载地址

  • FinallShell
    　Xshell 和 Xftp 的替代品，其实 ssh 命令已经挺好用的了，就是感觉还想要一款 Xftp 类似的软件，这款国内人做的软件不错，就是界面稍微丑了点，其他还好，就算是代替 Xftp 的吧。
    下载地址

  • PostMan
    tar.gz 解压版，需要手动配置启动图标
    官网下载地址

  • Typora
    官网下载地址
    tar.gz 解压版，需要手动配置启动图标

  • Itellij idea
    tar.gz 解压版，需要手动配置启动图标
    官网下载地址

  • Navicat
    tar.gz 解压版，需要 Wine 下才能运行，Deepin 发行版可直接运行，需要手动配置启动图标
    注：试用到期可删除 /home/guan/.navicat64/
    官网下载地址

  • ＷinFonts（解决缺失字体问题）
    将 Windows 系统 C:\Windows\Fonts 目录下所有字体文件复制进新创建的 WinFonts 文件夹里。将 ＷinFonts 移到Ｄeepin 的 /usr/share/fonts 目录下即可。

  • JD-GUI
    官网下载 deb 包，使用　sudo dpkg -i 命令安装。
    官网下载地址

  • TeamViewer
    官网下载 deb 包，使用　sudo dpkg -i 命令安装。
    会缺失：qml-module-qtquick-dialogs (>= 5.5) 和 qt56-teamviewer 依赖，使用如下命令安装依赖：

sudo vim ~/.bashrc
将 alias ll=’ls -l’ 的注释去掉，source ~/.bashrc 即可

sudo vim /etc/default/grub # 编辑 grub 文件
sudo update-grub # 更新 grub 设置
