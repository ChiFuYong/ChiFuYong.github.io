    Docker 环境安装 Oracle 11c

    chify2022-06-272022-12-29

    首先需要装好 Docker，CentOS 7 安装 Docker 可点击参考此文章

    下载 Docker Oracle 镜像

    docker pull jaspeen/oracle-11g

    注：此镜像没有 Oracle 安装包，里面有自动安装数据库的脚本，启动镜像容器时，需要容器卷下有相应的安装包（官网下载），所以 大小才281MB，需要自行下载 Oracle 11g 安装包。

    Oracle 官方安装包获取

    • 下载地址：Oracle 11g 官网下载，下载 linux.x64_11gR2_database_1of2.zip
      和 linux.x64_11gR2_database_2of2.zip 两个文件。如下图：

    • 将下载完的文件，使用 xftp 传输到装有 Docker 的 Linux 服务器上，并解压至 /root/oracleinstall，解压后目录如下图：

    启动 jaspeen/oracle-11g 镜像容器实例

    使用如下命令启动容器，注：-v /root/oracleinstall:/install 此容器卷必须添加，且安装包必须解压到对应容器卷宿主机的目录中。
