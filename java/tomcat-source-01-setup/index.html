    为什么读 Tomcat 源码

    Tomcat 是 Java 生态中最流行的 Web 容器之一，几乎所有 Java Web 开发者都用过它。读 Tomcat 源码能帮你理解：

    • Servlet 容器是如何工作的：一个 HTTP 请求从进来到出去，经历了什么
    • 线程模型：高并发场景下 Tomcat 是怎么处理请求的
    • 类加载机制：Web 应用的类隔离是怎么实现的
    • 设计模式实战：责任链、观察者、工厂模式在真实项目中怎么用

    Tomcat 架构总览

    在深入源码之前，先理解 Tomcat 的整体架构：

      graph TD
    A[Server] --> B[Service]
    B --> C[Connector 1 - HTTP]
    B --> D[Connector 2 - AJP]
    B --> E[Engine]
    E --> F[Host 1]
    E --> G[Host 2]
    F --> H[Context 1 - WebApp]
    F --> I[Context 2 - WebApp]
    H --> J[Wrapper - Servlet]

    核心组件说明：

    组件职责类比
    Server整个 Tomcat 实例一个公司
    Service一组 Connector + 一个 Engine一个部门
    Connector处理网络连接（HTTP/AJP）前台接待
    Engine请求处理引擎核心业务
    Host虚拟主机子公司
    Context一个 Web 应用一个项目组
    Wrapper一个 Servlet一个员工
